# Customer Refund Policy (Version 2.0 - Active 2025/2026)

## 1. Superseding Notice
This document completely supersedes and replaces Refund Policy Version 1.0 effective January 1, 2025.

## 2. Updated Eligibility Window
The refund window is extended from 14 days to 30 calendar days for all standard tier customers.
Enterprise tier customers receive an extended 60-day satisfaction guarantee window.

## 3. Zero Restocking Fees
All restocking and return processing fees have been eliminated. Customers receive a 100% full refund with zero deductions.
Digital software licenses are now fully refundable within 7 days if usage is under 1,000 API calls.

## 4. Expedited Payout Timeline
Approved refunds are now processed within 3 to 5 business days (down from 14 business days).
